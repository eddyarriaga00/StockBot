Connect Alpaca (one time, about 5 minutes)

  1. Sign up at alpaca.markets (free).
  2. In the Alpaca dashboard, switch to Paper Trading and click Generate API Keys.
  3. Paste both keys below, click Save, then pick Alpaca Paper above.

Keys are stored only on this Mac in data/settings.json (owner-only file).

Control from the website

Open eddyarriaga00.github.io/StockBot on any device and enter this passcode to trade and run the bot from there. Works while this Mac is on and StockBot is running.

Discord

Get trades, alerts, a daily summary after the close, and the weekly report card in a Discord channel.

  1. In Discord, open your server → Server Settings → Integrations → Webhooks → New Webhook.
  2. Pick the channel, click Copy Webhook URL, paste it below, and click Connect.

Separate channels (optional)

Give a channel its own webhook and that kind of message goes there instead of the main channel. The dashboard and the start-here guide only appear when they have their own channel.
